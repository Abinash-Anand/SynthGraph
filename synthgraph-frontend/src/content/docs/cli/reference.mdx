Every command below is shown as the tool prints it with `--help`, so this page matches the version you have installed. Run `synthgraph --help`, or `synthgraph <command> --help`, to see the same text locally.

## Global options

These go before the command: `synthgraph --json projects list`.

```text

 Usage: synthgraph [OPTIONS] COMMAND [ARGS]...

 Query, inspect and export SynthGraph provenance.

 Provenance is captured with the Python SDK while your research runs. This CLI is how you inspect
 and export it afterwards.

 Credentials come from the environment:


   export SYNTHGRAPH_API_KEY=...
   export SYNTHGRAPH_API_URL=https://your-synthgraph-backend

 There is deliberately no --api-key option: it would put your key into shell history and process
 listings.

+- Options ---------------------------------------------------------------------------------------+
| --json                                 Print machine-readable JSON from every command.          |
| --api-url                     <str>    SynthGraph backend URL. Defaults to $SYNTHGRAPH_API_URL. |
| --timeout                     <float>  Request timeout in seconds.                              |
| --version                              Show the installed version and exit.                     |
| --install-completion                   Install completion for the current shell.                |
| --show-completion                      Show completion for the current shell, to copy it or     |
|                                        customize the installation.                              |
| --help                -h               Show this message and exit.                              |
+-------------------------------------------------------------------------------------------------+
+- Commands --------------------------------------------------------------------------------------+
| compare        Compare two or more generation runs.                                             |
| manifest       Export the reproduction manifest for a generation.                               |
| docs           Export backend-generated Markdown documentation for a generation.                |
| auth           Inspect the identity behind the configured API key.                              |
| projects       List and inspect projects.                                                       |
| experiments    List, search and inspect experiments.                                            |
| generations    List and inspect generation runs.                                                |
| metrics        Declare and read the direction (maximize, minimize, neutral) of an experiment's  |
|                metrics.                                                                         |
| training-runs  List and inspect training runs, including capture-completeness status.           |
| evaluations    List and inspect evaluation results.                                             |
| assets         List and inspect asset references and their versions.                            |
| datasets       List and inspect dataset references and their versions.                          |
+-------------------------------------------------------------------------------------------------+
```

## `synthgraph manifest`

```text

 Usage: synthgraph manifest [OPTIONS] {generation_id}

 Export the reproduction manifest for a generation.

 The manifest records what would be needed to reconstruct the experiment.
 It is a record, not a runnable script, and it carries no dataset bytes and
 no credentials.

 Examples:

     synthgraph manifest <generation-id>

     synthgraph manifest <generation-id> --output reproduction.json

+- Arguments -------------------------------------------------------------------------------------+
| *    generation_id      <str>  Generation ID. [required]                                        |
+-------------------------------------------------------------------------------------------------+
+- Options ---------------------------------------------------------------------------------------+
| --output  -o      <path>  Write the manifest to this file instead of stdout.                    |
| --json                    Accepted for consistency; the manifest is always JSON.                |
| --help    -h              Show this message and exit.                                           |
+-------------------------------------------------------------------------------------------------+
```

### `synthgraph metrics set-direction`

```text

 Usage: synthgraph metrics set-direction [OPTIONS] {experiment} {metric}
                                         {direction}

 Declare whether a bigger or smaller value of a metric is better.

 Declaring the same direction again changes nothing. Declaring a different
 one than before is rejected and nothing is changed; use
 ``correct-direction`` to change it on purpose.

 Example:

     synthgraph metrics set-direction <experiment-id> loss minimize

+- Arguments -------------------------------------------------------------------------------------+
| *    experiment      <str>  Experiment ID. [required]                                           |
| *    metric          <str>  Metric key, exactly as it is logged. [required]                     |
| *    direction       <str>  maximize, minimize or neutral. [required]                           |
+-------------------------------------------------------------------------------------------------+
+- Options ---------------------------------------------------------------------------------------+
| --json            Print JSON instead of a table.                                                |
| --help  -h        Show this message and exit.                                                   |
+-------------------------------------------------------------------------------------------------+
```

### `synthgraph metrics correct-direction`

```text

 Usage: synthgraph metrics correct-direction [OPTIONS] {experiment} {metric}
                                             {direction}

 Correct a direction that was declared earlier, recording why.

 Only a metric that already has a declaration can be corrected.

 Example:

     synthgraph metrics correct-direction <experiment-id> loss minimize             --note
 "declared as maximize by mistake"

+- Arguments -------------------------------------------------------------------------------------+
| *    experiment      <str>  Experiment ID. [required]                                           |
| *    metric          <str>  Metric key, exactly as it is logged. [required]                     |
| *    direction       <str>  maximize, minimize or neutral. [required]                           |
+-------------------------------------------------------------------------------------------------+
+- Options ---------------------------------------------------------------------------------------+
| *  --note  -n      <str>  Why the earlier declaration was wrong. [required]                     |
|    --json                 Print JSON instead of a table.                                        |
|    --help  -h             Show this message and exit.                                           |
+-------------------------------------------------------------------------------------------------+
```

### `synthgraph training-runs link-generation`

```text

 Usage: synthgraph training-runs link-generation [OPTIONS] {training_run_id}
                                                 {generation_id}

 Record that a training run used a generation.

 The generation may be in another experiment, but must be in the run's own
 project. A link is exact and cannot be changed or removed afterwards.
 Linking the same pair again changes nothing. Use this to link runs that
 already exist; nothing links them automatically.

 Example:

     synthgraph training-runs link-generation <training-run-id> <generation-id>

+- Arguments -------------------------------------------------------------------------------------+
| *    training_run_id      <str>  Training run ID. [required]                                    |
| *    generation_id        <str>  Generation ID. [required]                                      |
+-------------------------------------------------------------------------------------------------+
+- Options ---------------------------------------------------------------------------------------+
| --json            Print JSON instead of a field list.                                           |
| --help  -h        Show this message and exit.                                                   |
+-------------------------------------------------------------------------------------------------+
```
