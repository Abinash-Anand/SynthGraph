# SynthGraph

SynthGraph is a platform for tracking, understanding, and reproducing
synthetic-data research experiments.

## Repository structure

- `sdk/` - Python SDK
- `backend/` - SynthGraph backend
- `docs/` - Architecture, API, and design documentation
- `examples/` - Example research workflows
- `infra/` - Infrastructure and deployment configuration

## Development status

Early development.

The Python SDK is currently the first implementation focus.

## Backend

### Tech Stack 

- NestJS server
- PostgreSQL DB
- Supabase DB Infra
- TypeORM
